# Mi Buen Fin

PWA para llevar el control de compras del Buen Fin y la Navidad: total comprado, mensualidades por mes (MSI), tope mensual y semáforo de presupuesto. Funciona sin internet y los datos se quedan en tu celular.

Reconstruir: `python tools/construir_app.py`. Pruebas: `node tools/prueba_logica.js` o `.\scripts\verify.ps1`.
